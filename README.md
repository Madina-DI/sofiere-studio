# Sofiere Studio

Портфолио AI-видео: ролики, кейсы и рабочие материалы студии.

## Что здесь

| Папка          | Что лежит                                                      |
| -------------- | -------------------------------------------------------------- |
| `projects/`    | По одной папке на ролик: описание, промпты, ссылка на готовое видео |
| `assets/`      | Обложки, кадры, исходники для превью                            |

Сами видеофайлы в репозиторий **не** кладём — они тяжёлые. В каждом кейсе
храним ссылку на видео (YouTube / Vimeo / облако) и кадр-превью.

## Как добавить новый кейс

1. Создать папку `projects/<название-ролика>/`
2. Скопировать туда шаблон `projects/_template.md` и переименовать в `README.md`
3. Заполнить: задача, инструменты, промпты, ссылка на результат
4. Добавить превью-кадр в `assets/`
